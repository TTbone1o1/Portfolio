# Portfolio

Single-page portfolio starter built with React, TypeScript, Vite, and `pnpm`.

## Run it

If `pnpm` is not installed globally, enable Corepack first:

```bash
corepack enable
```

Install dependencies:

```bash
pnpm install
```

Start the dev server:

```bash
pnpm dev
```

Create a production build:

```bash
pnpm build
```

Lint the project:

```bash
pnpm lint
```

## Customize

- Update the portfolio copy in `src/App.tsx`.
- Adjust the visual style in `src/App.css` and `src/index.css`.
- Replace the placeholder contact details with your own links.
